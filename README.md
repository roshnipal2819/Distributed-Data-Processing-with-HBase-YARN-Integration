## 🚀 HBase + YARN Distributed Processing with PySpark

A minimal setup to demonstrate distributed data processing using **Apache HBase**, **YARN**, and **PySpark**.

---

## 📁 Project Structure

- data_processing.py – PySpark data processing  
- hbase_operations.py – HBase read/write operations  
- requirements.txt – Python dependencies  

---

## ⚙️ Setup

1. Install Java, Hadoop, and HBase  
2. Configure Hadoop & HBase  
3. Install Python packages:  
   ```bash
   pip install -r requirements.txt
   ```

---

## ▶️ Usage

```bash
python data_processing.py    
python hbase_operations.py  
```
